# Atribuições de Imagens — Projeto Calcedônia

Este registo documenta todas as imagens utilizadas no dossiê documental do Concílio de Calcedônia, com licença, autor e fonte.

## Convênio de licenciamento

- Apenas imagens com **licença livre** (Creative Commons, domínio público ou equivalente) são aceites.
- Mapas e diagramas devem ser SVG originais criados como componentes — nunca copiados de livros ou sites.
- Imagens obtidas de Wikimedia Commons devem ter a licença verificada individualmente.
